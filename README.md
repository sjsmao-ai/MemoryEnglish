# 기억영어 MemoryEnglish v0.2

안드로이드 네이티브 학습 앱 프로젝트입니다.

## 이번 버전 핵심
- 메인 영역: 오늘 학습 / 단어 / 회화 / 문법 / 약점 복습
- 단어는 별도 학습 영역으로 유지
- 회화는 처음 5일 영어+뜻+음성+강세 노출 후 랜덤 회상 테스트
- 문법은 실제 회화 문장으로 학습하며 별도 기억 단계 저장
- 문법 Day 1~5 설명+예문, 이후 한글→영어 직접 말하기
- 단어·회화·문법 오답을 약점 복습에서 다시 학습
- 반복 오답 시 해당 항목만 기억 단계 초기화
- 회화 강세 단어는 더 크고 굵게 표시
- Android SpeechRecognizer 기반 문장 일치도 확인 및 TTS 듣기

## 기본 문법 세트
현재형, be going to, 현재 부정, 과거형, 과거 부정(didn't + 동사원형), can/can't, couldn't, want to, have to, Do you...?

## 빌드
Android Studio에서 이 폴더를 열고 Gradle 동기화 후 Run 또는 Build APK를 사용하세요.
현재 소스는 compileSdk 35 / minSdk 26 / targetSdk 35 기준입니다.

주의: 현재 발음 평가는 음성인식 결과와 정답 문장의 일치도입니다. 실제 음소·강세·리듬 채점은 별도의 발음평가 엔진을 붙이는 다음 단계 기능입니다.
